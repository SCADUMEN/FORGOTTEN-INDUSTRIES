Supplement to the sighting log

It leaves things behind.

Not every trace is a sighting. Some are olive-drab steel boxes, latched shut and put back where they were found. Each one holds a log and a clue. Each clue points somewhere else.

Contents of every can

  • A logbook Sign it with a handle, the date, and the time. Every name in it is a witness.
  • One clue card Photograph it. Leave it. The next person needs it as much as you did.
  • Nothing else, usually If you find something that isn't on this list, write it down before touching it.

Finding a Can

  1. Get to the spotCoordinates get you close, within about 30 feet. The last stretch is on you.
  2. Look, don't digNo can is ever buried. Check under, behind, and inside, never beneath the ground.
  3. Sign and photographLog your handle and time. Photograph the clue card, not the hiding spot.
  4. Put it backLatch it and return it exactly as found. Then file what you saw.

Field Terms

GZ
Ground zero. Where the coordinates say the can is.
DNF
Did not find. File it anyway. A DNF is still data.
ROT13
How hints are scrambled: each letter shifted 13 places, so no one reads them by accident.
Muggle
Anyone not looking. Don't search in front of them.

Addendum · Unconfirmed pattern

Two filed reports mention a small aircraft overhead in the minutes before a sighting. Low, quiet, gone before anyone thought to look for it.

If you see one, note the time. If you carry something that can listen to what it broadcasts, listen.
