# Who Is J.J.Ammo Can

Project id: `FI-PROJ-011`

Status: concept capture — 2026-09-01. Not yet built.

## Purpose

A bespoke ARG (alternate reality game), Carmen Sandiego-style: a mysterious
figure, known only as **JJAMMOCAN**, is spotted around different cities in
the United States. Identifying appearance: a large-brim sun hat and goggles.
The hat is a specific real product — the **Henschel Breezer** (Matthew's own
term for it: "Heschnel Breeze"), sold by **Hat Man Jacks** (Wichita, KS).
Double snap brim (3"), pinched front crown (4½"), cotton canvas, colors
Khaki/Green/Distressed Gold/Earth/Black, made in USA.

## Origin note

This project exists only as a concept as of this capture. It is unrelated to
the ATLAS assistant's use of "Who is JJ Ammo Can?" as an internal test phrase
for its own "Who is X?" skill-routing feature (see ATLAS commits `#35`/`#38`)
— that phrase was coincidental, not a reference to this project.
