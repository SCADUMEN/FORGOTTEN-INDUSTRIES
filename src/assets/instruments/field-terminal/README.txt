INSTALLATION

1. Save the PNG to the phone.
2. Apply it to the lock screen without enlarging it past the frame.
3. Use solid black (#000000) for the paired home screen.
4. If the operating system supports icon tinting, use oxide green (#4ADE80).
5. Keep one calm page of essential apps. Move the remainder without deleting
   them.

ADAPTATION

Open fi-field-terminal-source.html in a text editor. Palette tokens live at the
top of the style block; visible copy lives near the bottom of the document.
Render or capture the document at 1320 x 2868 pixels. Different screen ratios
may need deliberate repositioning. Preserve the upper clock-clearance field.
